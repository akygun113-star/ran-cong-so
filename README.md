# Rắn công sở 🐍⏰

Game rắn săn mồi phiên bản công sở: đầu rắn là Deadline, mồi là nhân viên, thua thì sếp cầm búa phán "KHÔNG ĐẠT KPI!".

- Một file `index.html` duy nhất, không cần cài đặt, chơi offline được.
- Ghép ảnh mặt vào đầu deadline, nhân viên, sếp (thư viện tối đa 50 ảnh, lưu trong trình duyệt).
- Điều khiển: phím mũi tên / WASD, vuốt màn hình hoặc bấm nút. Phím cách để tạm dừng.
